# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue or pull request: use
**Security → Report a vulnerability** on this repository's GitHub page. Include the SDK version,
what you found, and how to reproduce it.

## Supported versions

Security fixes are released for the latest minor version of the SDK. Upgrade to the newest
release to receive them.

## Credentials

Never include a real `client_secret` or access token in a report, issue or pull request. If you
believe a FlexFund credential has been exposed, rotate it in FlexFund right away.
